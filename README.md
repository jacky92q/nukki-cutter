# Nukki Cutter ✂️

이미지를 끌어다 놓거나 클릭해서 불러오면, **배경을 자동으로 제거(누끼)** 하고
투명 배경 PNG 로 **자동 다운로드**까지 해주는 웹 도구입니다.

> 모든 처리는 **여러분의 브라우저 안에서만** 이루어집니다.
> 이미지가 서버로 전송되지 않으므로, 보안이 중요한 환경에서도 안심하고 사용할 수 있습니다.

## 특징

- 🖱️ **드래그 앤 드롭** 또는 클릭으로 사진첩·파일에서 이미지 불러오기
- 🤖 **자동 모드** — ISNet 모델이 사진 속 주요 피사체를 자동으로 잡아 배경 제거 → 투명 PNG **자동 다운로드**
- 🎯 **지정 모드** — **브러시로 남길 부분을 직접 칠해** 원하는 영역만 누끼. 모델/네트워크가 필요 없어 어떤 환경에서도 항상 동작
- 🔒 **완전 로컬** — 네트워크로 이미지가 나가지 않음 (모델 파일만 최초 1회 캐싱)
- 📱 **앱으로 설치(PWA)** — 크롬/엣지에서 앱처럼 설치, 가위 아이콘 · 오프라인 동작
- 🎚️ 자동 모드 품질 선택: **최고 품질**(`isnet`) / **빠른 속도**(`isnet_fp16`)
- 🎨 흰색 바탕 + 네이비 브랜드 테마

## 기술 스택

- React 18 + TypeScript
- Vite
- [`@imgly/background-removal`](https://github.com/imgly/background-removal-js) — 자동 모드 배경 제거 엔진 (ISNet, CPU/WASM)
- Canvas 2D — 지정 모드 브러시 마스킹(외부 모델 불필요)

## 실행 방법 (로컬)

```bash
npm install
npm run dev
```

터미널에 표시되는 주소(기본 `http://localhost:5173`)를 브라우저에서 열면 됩니다.

### 프로덕션 빌드

```bash
npm run build      # dist/ 생성
npm run preview    # 빌드 결과 미리보기
```

`dist/` 폴더는 어떤 정적 호스팅(사내 인트라넷, 파일 서버 등)에도 그대로 올릴 수 있습니다.

## 자동 배포 (GitHub Pages)

`main` 브랜치에 푸시하면 `.github/workflows/deploy.yml` 이 자동으로 빌드해
GitHub Pages 에 배포합니다. → **https://jacky92q.github.io/nukki-cutter/**

> **최초 1회만 수동 설정이 필요합니다** (GitHub 보안 정책상 워크플로 토큰으로는
> Pages 를 처음 켤 수 없습니다):
>
> 저장소 **Settings → Pages → Build and deployment → Source** 를
> **`GitHub Actions`** 로 선택하세요.
>
> 한 번 켜두면 이후에는 `main` 에 푸시할 때마다 완전 자동으로 배포됩니다.

## 앱으로 설치 (PWA)

크롬·엣지에서 https://jacky92q.github.io/nukki-cutter/ 에 접속하면 주소창 오른쪽에
**설치 아이콘**(⊕ / 모니터 아이콘)이 나타납니다. 누르면 가위 아이콘의 독립 앱으로
설치되어 데스크톱·시작 메뉴·작업표시줄에서 바로 실행할 수 있고, 한 번 방문한 뒤에는
오프라인에서도 동작합니다.

> 로컬에서 설치형으로 확인하려면 `npm run build && npm run preview` 후
> 표시되는 주소(기본 `http://localhost:4173/nukki-cutter/`)로 접속하세요.
> (개발 모드 `npm run dev` 에서는 서비스 워커를 등록하지 않습니다.)

## 사용 방법

이미지를 화면에 끌어다 놓거나, 영역을 클릭해 파일을 선택한 뒤 모드를 고릅니다.

### 자동 모드

1. (선택) 품질을 고릅니다.
2. **작업 시작** 버튼을 누릅니다.
3. 배경이 제거되면 투명 PNG 가 자동으로 다운로드됩니다.

### 지정 모드 (브러시로 직접 칠하기 · 모델 불필요)

1. 모드 탭에서 **지정** 을 선택합니다.
2. **브러시** 로 남기고 싶은 부분을 칠합니다. (굵기 조절 가능)
3. 잘못 칠했으면 **지우개** 로 지웁니다.
4. **누끼 만들기** 를 누르면 칠한 영역만 남은 투명 PNG 가 자동 다운로드됩니다.

## 참고

- 지원 형식: PNG · JPG · WebP
- 최초 실행 시 모델 파일(수십 MB)을 한 번 내려받아 캐싱합니다. 이후에는 오프라인에서도 동작합니다.
- WebGPU 를 지원하는 최신 브라우저(Chrome/Edge 등)에서 가장 빠릅니다. 미지원 시 자동으로 CPU(WASM)로 동작합니다.
